# Synthwave & Retrowave Icecast Radio Streams

A curated list of direct Icecast/mountpoint stream URLs for synthwave, retrowave, darksynth, and related retro-electronic radio stations.

---

## Nightride FM Network
*High-quality direct streams (up to 320 kbps MP3).*

- **Nightride FM** (Main Synthwave / Outrun)  
  `https://stream.nightride.fm/nightride.mp3`  
  *AAC/M4A Stream:* `https://stream.nightride.fm/nightride.m4a`

- **Chillsynth FM** (Downtempo / Chillwave / Synth Ambient)  
  `https://stream.nightride.fm/chillsynth.mp3`

- **Darksynth FM** (Cyberpunk / Heavy Darksynth / Industrial)  
  `https://stream.nightride.fm/darksynth.mp3`

- **Spacesynth FM** (Space Disco / Italo / Cosmic Synth)  
  `https://stream.nightride.fm/spacesynth.mp3`

- **Datawave FM** (IDM / Synthwave / Glitch)  
  `https://stream.nightride.fm/datawave.mp3`

- **EBSM** (Electronic Body Synth Music)  
  `https://stream.nightride.fm/ebsm.mp3`

## Quick Usage Notes

### Command Line (`mpv`)
```bash
mpv https://stream.nightride.fm/nightride.mp3
```

### Command Line (`cmus`)
Inside `cmus`, press `5` (browser view) or `:add <url>`:
```text
:add https://stream.nightride.fm/chillsynth.mp3
```
